# QA Inventory

- 对象浏览：连接树展开、表列表、对象详情、建表语句预览。
- AI 查询：查询页签、SQL 编辑器、执行结果表格、对话侧栏。
- 表数据：表格结果、详情侧栏、分页栏。
- 表结构编辑：字段页、索引页、SQL 预览栏。
- 对象定义编辑：视图定义 SQL、保存/格式化/复制按钮。
- 智能 ER：关系图、FK 关系列表、布局/线型控制。
- 历史/快照：顶部历史下拉、ER 快照入口。
- 知识中心：样例 SQL 列表、详情面板、保存/重置/删除按钮。
- Redis 浏览：键层级、TTL、详情面板。
- 设置：界面语言、深色模式、隐私政策入口。
