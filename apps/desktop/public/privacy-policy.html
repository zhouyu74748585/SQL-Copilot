二、数据收集与使用

2. Data Collection & Usage

✓ 无数据收集  本应用不收集、不存储、不传输任何用户个人数据。

SQL Copilot 是一款运行在您本地设备上的桌面应用程序。您在应用内输入的所有 SQL 语句、数据库连接配置及查询结果均仅保存在您自己的设备本地，不会上传至任何服务器。

我们不会收集、分析或存储以下任何类型的数据：

  • 个人身份信息（姓名、邮箱、手机号等）
  • 设备标识符或遥测数据
  • 使用行为日志或崩溃报告
  • 您的数据库内容或 SQL 查询记录
✓ No Data Collection  The Application does NOT collect, store, or transmit any personal user data.

SQL Copilot is a desktop application that runs entirely on your local device. All SQL statements, database connection configurations, and query results you enter within the application are stored only on your own device and are never uploaded to any server.

We do not collect, analyze, or store any of the following types of data:

  • Personal identification information (name, email, phone number, etc.)
  • Device identifiers or telemetry data
  • Usage logs or crash reports
  • Your database contents or SQL query history

The Application supports integration with external AI model providers (e.g., OpenAI, Anthropic, Azure OpenAI). However, all integration configurations are set up entirely by the user. The Application does not record or store your API keys or any content exchanged with AI service providers.
