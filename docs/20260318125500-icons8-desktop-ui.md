# Icons8 替换与桌面端视觉优化

## 目标
- 用 `assets/icons` 规范命名资源替换原 `assets/db` SVG，对象树分类/叶子使用 Icons8；events/backups 仍用 Ant 图标。
- 弱化网页感：中性灰底、系统字体、扁平面板与页签、实色 AI 气泡、Electron 窗口底色对齐。

## 关键改动
- **图标**：`mysql/mongo/postgresql/redis/sqlite/sqlserver/oracle` + `tree-*` 共 14 个文件；删除 `assets/db/*.svg`。
- **逻辑**：`useStudioRuntime` 中 `dbIconUrl`、`treeNodeIconUrl`、`treeTitleIconSrc`；`StudioShell` 树标题统一 `<img>` 或 Ant 回退。
- **样式**：`tokens.css` 定义 `--font-ui` 与 shell 背景令牌；`shell.css` 浅色/深色 token 与工具栏、页签、树图标框；`style.css` 面板去毛玻璃与大阴影；`antdThemeConfig` 主色/圆角/Tree 行高；`electron/main.cjs` `backgroundColor` 与 Win/Linux `titleBarOverlay`。

### 2026-03-18 补充
- **代理问题修复**：系统配置 HTTP 代理时导致 localhost 请求返回 502，`package.json` 中 `dev:renderer`、`dev:electron`、`debug:main` 脚本添加 `NO_PROXY=localhost,127.0.0.1`；`run-electron-main.cjs` 中同步添加 `NO_PROXY` 设置。
- **背景色统一**：`--bg-app` 从 `#e8e8e8` 调整为 `#ececec`（更中性灰），与 Electron `backgroundColor` 保持一致。
- **顶栏优化**：Chrome 高度从 48px 降至 38px（Windows/Linux 标题栏覆盖区同步调整），工具栏内边距从 12px 减至 10px，按钮高度从 36px 降至 32px。
- **页签扁平化**：移除卡片式悬浮感，改为底边高亮条 + 扁平背景，去除 `border-radius: 8px` 改为 `4px`，去除 `background: #fff` 改为透明/半透明。
- **面板去渐变**：工作区背景、面板标题、工具栏、查询区等从彩色渐变/高亮蓝白底改为中性灰 `surface-1/surface-0` 统一风格。
- **AI 气泡实色**：用户消息气泡从多色渐变 + 阴影改为纯色（`#3d6eae` 等）无阴影，更工具窗口风格。
- **分隔条简化**：从彩色渐变 `#eef3fb` → `#e3ecf9` 改为纯色 `surface-2`。
- **字体栈优化**：`shell.css` 根字体从 `var(--font-ui)` 改为直接使用系统字体栈 `-apple-system, BlinkMacSystemFont, 'Segoe UI', 'PingFang SC', ...`

## 验证
- `apps/desktop`：`npm run build`、`npm run type-check` 均通过。
- Electron 启动：`npm run -w @sqlcopilot/desktop debug` 可正常打开窗口。

## 遗留
- 深色主题下部分 PNG 图标若有白边，可后续加暗色版或 `filter`。
- titleBarOverlay 仅匹配浅色默认；暗色主题与标题栏同步可后续 IPC。
