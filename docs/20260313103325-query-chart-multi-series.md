# 主题：query-chart-multi-series

## 记录

### 2026-03-13 10:33:25

## 本次目标
- 为 `LINE`、`BAR`、`TREND` 增加按分组字段拆多系列的自动绘图能力。
- 支持趋势图在单图中按分类展示多条线，并确保横轴维度唯一且不重复。

## 关键改动
- 共享协议 `packages/shared-contracts/src/index.ts`
  - 为 `ChartConfigVO` 新增 `seriesField` 字段，支持多系列分组配置。
- 后端 `apps/server/src/main/java/com/sqlcopilot/studio/service/impl/AiServiceImpl.java`
  - 更新图表 system prompt，允许返回 `seriesField`。
  - 增强图表配置归一化与校验：`LINE/BAR/TREND` 在 `seriesField` 模式下要求 `yFields` 仅 1 项。
  - 更新图表摘要，分组模式输出 `X + Y + 分组字段`。
- 后端 `apps/server/src/test/java/com/sqlcopilot/studio/service/impl/AiServiceImplChartConfigTest.java`
  - 新增图表配置测试，覆盖分组模式合法/非法校验与归一化。
- 前端 `apps/desktop/src/modules/studio/composables/useStudioRuntime.ts`
  - 为手动图表配置增加 `seriesField`、分组字段候选、单 Y 约束和对应交互处理。
  - 更新图表摘要和可渲染校验，兼容旧的多 Y 模式与新的分组模式。
- 前端 `apps/desktop/src/modules/studio/components/StudioShell.vue`
  - 在图表手动面板增加“分组字段”选择器。
  - 选择分组字段后，`LINE/BAR/TREND` 的 Y 轴自动切换为单值选择。
- 前端 `apps/desktop/src/components/QueryChartPanel.vue`
  - 为 `LINE/BAR/TREND` 增加分组透视渲染路径。
  - 同一 `X + 分组` 的重复记录自动求和；X 轴去重；缺失点位补 `null`。
- 前端 `apps/desktop/src/i18n/messages.ts`
  - 增加“分组字段”“Y 轴（单值）”和分组图表相关提示文案。
