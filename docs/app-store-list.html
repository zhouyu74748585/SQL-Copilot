完整描述（应用商店正文）

Full Description (App Store Body)

中文完整描述

SQL Copilot 是一款 AI 原生桌面数据库工作台。它不只是一个"输入问题、吐出 SQL"的简单工具，而是把 AI 对话、SQL 生成、风险评估、结果执行、图表展示、ER 分析和知识记忆整合为一体的完整智能工作台。


🤖 真正懂上下文的 AI Copilot
内置 RAG 检索增强，AI 在生成 SQL 前会自动关联当前数据库的 Schema、表字段说明、历史 SQL 样例、自定义术语与多轮会话记忆，让每次回答都真正基于你的数据库，而不是通用模板。


🗄 多数据库，一套工作台
支持 MySQL、PostgreSQL、SQL Server、Oracle、SQLite 五大主流数据库。统一的连接管理界面，支持 SSH 隧道、只读模式、多环境标识（开发 / 测试 / 生产）。


⚡ SQL 生成不是终点，执行闭环才是
AI 生成 SQL 后可一键执行。执行前内置风险评估引擎，自动拦截全表删除、无 WHERE 条件的 UPDATE、生产环境写入等高风险操作，让数据库操作更安全。


📊 数据可视化，不需要切换工具
支持自然语言生成聚合分析 SQL 并自动渲染图表（折线图、柱状图、饼图等），图表可导出为图片，查询结果可导出 CSV。


🔍 智能 ER 图
不只展示外键关系，还能由 AI 推断隐式表关联关系，帮助快速理解复杂库结构。支持快照保存，随时恢复和继续分析。


🔒 完全本地，数据不离机
所有数据库连接配置、Schema 信息和历史记录均存储在本地，不经过任何云端服务器。AI 模型由用户自行配置（支持 OpenAI、Azure OpenAI 及任意兼容 API），本应用不记录任何 AI 交互内容。


📚 知识库管理
支持自定义术语、样例 SQL 管理，可从历史查询一键保存为样例，向量化后作为 AI 上下文的一部分，让 AI 越用越懂你的业务。

English Full Description

SQL Copilot is an AI-native desktop database workbench. It goes far beyond a simple "ask a question, get a SQL" tool — it integrates AI conversation, SQL generation, risk assessment, execution, data visualization, ER diagram analysis, and knowledge memory into a single, unified intelligent workbench.


🤖 A Copilot That Truly Understands Context
Built-in RAG (Retrieval-Augmented Generation) ensures the AI automatically retrieves your database's Schema, field descriptions, historical SQL examples, custom terminology, and multi-turn conversation memory before generating SQL — so every answer is grounded in your actual database, not generic templates.


🗄 Multi-Database, One Workbench
Supports MySQL, PostgreSQL, SQL Server, Oracle, and SQLite. Unified connection management with SSH tunnel support, read-only mode, and multi-environment tagging (Dev / Test / Prod).


⚡ SQL Generation Is Not the End — Execution Closure Is
Once SQL is generated by AI, execute it with one click. A built-in risk assessment engine automatically blocks high-risk operations such as full-table deletes, UPDATE without WHERE, and writes to production environments.


📊 Data Visualization Without Switching Tools
Describe aggregation queries in natural language and get auto-rendered charts (line, bar, pie, etc.). Charts can be exported as images; query results can be exported as CSV.


🔍 Intelligent ER Diagrams
Not just foreign key relationships — AI can infer implicit table associations, helping you understand complex schema structures at a glance. Snapshots can be saved and restored at any time.


🔒 Fully Local — Your Data Never Leaves Your Machine
All connection configs, schema information, and history are stored locally. No cloud servers involved. AI models are configured by you (OpenAI, Azure OpenAI, or any compatible API); the app never logs AI interactions.


📚 Knowledge Base Management
Manage custom terminology and example SQL snippets. Save queries to the knowledge base with one click. After vectorization, they become part of the AI context — the more you use it, the better it understands your business.
