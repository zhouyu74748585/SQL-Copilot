# 主题：rag-local-mode-ui

## 记录

### 2026-03-14 19:20:00

## 本次目标
- 修复向量化配置中从在线模式切换到本地模式后，运行模式联动不正确的问题。
- 当本地 ONNX 模式启用时，在界面下方补充模型下载提示，并支持中英双语。

## 关键改动
- `apps/desktop/src/modules/studio/components/StudioShell.vue`
  - 为向量模型运行模式下拉框新增 `handleEmbeddingProviderTypeChange`。
  - 当用户将向量模型运行模式从在线切换为本地，且已启用 Rerank 时，同步更新 Rerank 运行模式，避免上下配置卡片状态不一致。
  - 为 Rerank 开关新增 `handleRerankEnabledChange`。
  - 当用户在本地向量模式下启用 Rerank 时，Rerank 运行模式自动跟随当前向量模型运行模式。
  - 在本地 ONNX 模式分支下新增下载提示：
    - Embedding 模型链接：https://huggingface.co/hooman650/bge-m3-onnx-o4/tree/main
    - Rerank 模型链接：https://huggingface.co/swulling/bge-reranker-base-onnx-o4/tree/main
  - 提示文案按当前界面语言动态显示中英文。
  - 新增最小样式，保证提示块在当前设置卡片中正常展示。
